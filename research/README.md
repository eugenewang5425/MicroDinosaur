# MicroDinosaur 仿真研究记录

这份索引供复盘步态和传动试验。整机仿真的冻结 Demo 1 使用 19 个驱动轴。仓库默认分支的 OS-M02 是另一个发布对象，采用 6 条保留驱动。仿真结果不构成实机验收。

| 时段 | 研究方向 | 状态与续用范围 |
| --- | --- | --- |
| 2026-09 | 指令延迟、控制奖励、足底接触、折叠、起身、跳跃和前进等级 | 历史对照。沿用时间和接触口径前先核对对应模型、策略和命令 |
| 2026-10 上旬 | J288 适配、静站、步态和速度、头尾惯量与跳跃 | 历史模型族，单独保留指标 |
| 2026-10 中下旬 | 接触结构、软结构、折叠接触和起身 | 保留机械假设与接触诊断 |
| 2026-10 末起 | 统一 Demo 1 的平地、起身和地形研究 | 冻结平地模型及策略供重放。地形结果按各自条件验收 |
| 2026-11-13 至 24 | 六轴执行器、结构间隙与承重校准 | [归档](s288_calibration_20261124.md)，停止作为步态训练环境 |
| 2026-11-24 起 | 从原生 Demo 1 逐级改变驱动与接触参数 | [新研究分支](https://github.com/eugenewang5425/MicroDinosaur/tree/research/demo1-domain-randomization/research/demo1_domain_randomization) |

本地项目的 `research/RESEARCH_INDEX.md` 按时间列出研究目录和存量报告。六轴归档内的 `manifest.json` 将关键快照的来源、大小与 SHA-256 逐项对应。完整日志和模型在本地复核。

参见[分支管理](BRANCHES.md)。
