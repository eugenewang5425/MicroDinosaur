# 六轴执行器校准试验归档

2026-11-24 停止从这套校准动力学续训步态。这里的六轴指在冻结 Demo 1 整机上更换传动模型的六个驱动轴 `A1 / A4 / A6 / A7 / A8 / A9`。它的轴侧曲线拟合、关节轴与连杆侧间隙，以及整机受载换向属于不同的验证问题。

| 证据 | 结果 |
| --- | --- |
| 长跑停止检查点 | 1,123 套候选，累计 4,492 次短回放。四秒稳定前进及归零起十秒停车无联合通过 |
| 同状态、同逐轴输入的积分配对 | 从 0.18 秒的同一状态分支，两个起步工况在 0.625 ms 各出现 15.625 ms、12.5 ms 双足同时失载。0.3125 ms 两组均未失载 |
| 无前进命令的 10 秒静站 | 2/2 通过，两档积分各一例 |
| 单步后改变撤令相位 | 6 个相位、每个两档积分，12/12 跑出单个有效迈步，0/12 严格停稳 |
| 单步捕获修正的独立复测 | 有效单步由 1/6 变为 2/6，更新后的严格单步及停车 0/6 |

亚步对照说明仅看 50 Hz 曲线可能漏掉短时失载，整机接触结果对积分方案也敏感。静站通过只能说明对应初态能维持站立。受载换向、落脚到承重的连续性以及停车滑移要各自检验。

本地校验清单保留冻结原生回放、逐轴目标和实际角度、左右足承重、机身 IMU、旧候选及评分、配对积分样本、单步同屏与重现实验协议。原始试验目录保留原址。以后从同一方向加载时，先在独立固定载荷试验中核对轴角和足端几何，再用两档积分验证接触响应。
